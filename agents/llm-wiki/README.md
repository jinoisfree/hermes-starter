# LLM 위키

근거를 모아 재사용할 지식으로 정리

대화와 자료의 핵심을 위키·학습 절차로 정리합니다.

Slack 앱·봇 토큰과 모델 제공자를 직접 연결한 뒤 사용합니다. 토큰은 이 저장소에 넣지 않습니다.
`config.yaml`의 자리표시를 `hermes setup`으로 채우고, 선택 서비스는 필요한 것만 연결합니다.
위키 저장소·검색은 직접 연결 필요.
자료의 출처와 불확실성을 기록합니다.

개인 계정 도구·자동 예약·자동 전송·자동 위임은 포함하지 않습니다.
협업 상대는 `agent.yaml`에 설명하며, 실제 설치된 상대 목록은 설치 홈의
`.starter/collaboration`에서 마지막 번호의 JSON 조각을 확인합니다. 도구 연결은 직접 해야 합니다.
